## Integration Patterns & Gotchas

**DTP ↔ dispatch-automation sync:** Talent pool group changes flow via Kafka (`marketplace-administration.publish_groups`). dispatch-automation consumes these to keep its publish groups in sync.

**Payload field name constraint:** Integration API can rewrite URL paths for naming consistency, but cannot rename payload field names. This limits how much the naming inconsistency can be papered over downstream.

**Jeff's visibility requirements:** Wants updates in "Now Next Later" structure with a visual progress matrix showing deployment status, lessons learned, team testing/approval, and branch plans. Weekly NetDev sync (upgraded from bi-weekly).

**Service Territory ↔ Reporting coupling:** Jeff stresses these must be developed almost simultaneously — reporting outcomes influence how territory tooling is built. Also feeds into white space strategy and defaults vs. custom zip code storage decisions.
